# GeneWeaver

**GPU-Accelerated CRISPR Alignment Engine**

GeneWeaver is an individual internship project focused on exploring efficient DNA sequence alignment and GPU acceleration for CRISPR-related sequence analysis.

## Project Objectives

- Develop a sequence alignment workflow for DNA sequences.
- Establish a CPU-based reference implementation.
- Investigate GPU acceleration for computationally intensive alignment tasks.
- Validate alignment correctness through automated tests.
- Benchmark CPU and GPU execution where supported.
- Document implementation decisions, limitations, and results.
